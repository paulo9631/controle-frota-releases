# Controle de Frota

Instalador do app de controle de frota da Global Óptica.

[Baixar o instalador](https://github.com/paulo9631/controle-frota-releases/releases/latest/download/ControleFrota-Instalador.exe)

Depois de instalado, o app se atualiza sozinho.

Na primeira instalação, o Windows pode mostrar um alerta azul. Clique em "Mais informações" e depois em "Executar assim mesmo".

Este repositório guarda só o instalador. Nenhum dado da frota fica aqui.
